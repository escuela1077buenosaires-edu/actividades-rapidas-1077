# Actividades rapidas 1077

Sistema independiente para publicar actividades HTML elegidas por el AIE.

- `archivo/`: conserva los HTML originales, habilitados o no.
- `docs/`: contiene solamente el indice y las actividades publicadas en GitHub Pages.
- `catalogo-archivo.json`: estado administrativo completo.

La administracion se realiza desde la Bandeja Local. No se almacenan secretos en este repositorio.
